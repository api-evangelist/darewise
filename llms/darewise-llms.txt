# Darewise (Life Beyond Studios)

> Darewise Entertainment is a European game studio — Paris, London, Barcelona — founded by AAA
> industry veterans and building Life Beyond, a free-to-play sci-fi MMO on Unreal Engine 5 set on the
> alien world Dolos, with Web3 asset ownership (NFTs and ERC-20 tokens) and player-driven settlement
> and governance. Animoca Brands announced the acquisition of a majority stake in April 2022, and the
> studio now operates as Life Beyond Studios.
>
> Darewise publishes NO public API, developer portal, or API documentation. There is no OpenAPI,
> AsyncAPI, GraphQL, MCP, or A2A surface on any host it operates. This file is generated by API
> Evangelist from a third-party profile; it is not published by the company.

## Status of the machine-readable surface

- No OpenAPI / Swagger document on any Darewise or Life Beyond Studios host (probed 2026-08-17).
- No GraphQL endpoint; /graphql on the live host returns a Cloudflare bot challenge, not a schema.
- No MCP server, no A2A agent card, no /.well-known/ documents — every /.well-known/ path returns a
  real origin 404.
- No api., docs., or developer. subdomain resolves in DNS on either domain.
- The legacy brand host www.darewise.com is offline: DNS resolves, but TCP 443 and 80 refuse
  connections. Its last Internet Archive capture serving HTTP 200 is 2025-04-21.

## Open source

- [github.com/Darewise](https://github.com/Darewise): 14 public repositories, mostly forks of Unreal
  Engine and Perforce tooling. Four are first-party: an AsyncAPI generator template for Unreal
  Engine, a changelist-description tool (`clever`), a Perforce secret-detection integration
  (`p4-detect-secrets`), and a C++ `VariableRenamer`.
- [asyncapi-template-cpp-ue](https://github.com/Darewise/asyncapi-template-cpp-ue): Apache-2.0
  AsyncAPI Generator template `cpp-ue` that renders a compilable Unreal Engine C++ module from an
  AsyncAPI 3.x document. The studio publishes the TOOL but not any AsyncAPI document of its own.
